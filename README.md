# 프리코스 3주차 - 로또

## 구현할 기능

### 입력

- [ ] 구입 금액 입력 받기

- [ ] 당첨 로또 번호 입력 받기

- [ ] 보너스 번호 입력 받기

### 로또 관련

- [ ] 구입 금액에 해당하는 만큼 로또를 발행하는 기능

- [x] 랜덤 로또 번호를 생생하는 기능

- [x] 로또 번호를 오름차순 정렬하는 기능

- [ ] 로또 번호를 당첨 번호와 비교하는 기능

- [ ] 로또 번호에 보너스 번호가 있는지 확인하는 기능

### 구입 금액 관련

- [ ] 구매 개수(구입 금액/1000)을 반환하는 기능

### 결과 관련

- [ ] 순위를 구하는 기능

- [ ] 수익률을 구하는 기능

### 검증

- [x] 로또 번호의 숫자 범위가 1~45인지 확인

- [x] 보너스 번호의 숫자 범위가 1~45인지 확인

- [x] 한 로또에 중복된 번호가 있지 않은지 확인

- [x] 보너스 번호가 당첨 로또와 중복되지 않은지 확인

- [ ] 구입 금액이 1000단위가 맞는지 확인

### 출력

- [ ] 구매한 로또들을 출력

- [ ] 당첨 통계 출력

- [ ] 수익률 출력

### 예외처리

- [ ] 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받음

### 기타

- [ ] 당첨 번호 문자열을 파싱
